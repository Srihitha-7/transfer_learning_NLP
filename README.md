# Transfer Learning for NLP using TensorFlow

This project demonstrates transfer learning for NLP using TensorFlow and TensorFlow Hub.

## Models Used

- GNews Swivel (20D)
- NNLM (50D)
- NNLM (128D)
- Universal Sentence Encoder
- Universal Sentence Encoder Large

## Technologies

- TensorFlow 2.20
- TensorFlow Hub
- TensorBoard
- Keras

## Features

- Sentence embeddings
- Binary text classification
- Early stopping
- TensorBoard visualization
- Transfer learning
